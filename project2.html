Relational Database System - Pet Boarding Management

Project Overview

Institution: University of Central Florida

Location: Orlando, FL

Duration: August 2024 – December 2024

Project Image

Project Description

This project involved designing and implementing a comprehensive relational database system for managing a pet boarding business using MySQL. The database system handles all aspects of pet boarding operations including pet information, client management, employee tracking, boarding schedules, and financial transactions.

The system encompasses 16 interconnected tables that manage diverse entities including pets, breeds, pet types, colors, clients, employees, positions, work schedules, boarding records, and various lookup tables. The database design follows normalization principles to ensure data integrity, eliminate redundancy, and maintain referential integrity across all relationships.

A key component of this project was the implementation of advanced database features including stored functions and triggers to automate business logic. These include automatic payroll deposit calculations based on employee work schedules and position rates, as well as data validation triggers that enforce business rules and maintain data consistency across the system.

The project required creating comprehensive Entity-Relationship (ER) diagrams to visualize the database structure, writing complex SQL queries involving multiple table joins and aggregations, and developing structured test cases to validate data integrity and query correctness throughout the development process.

Database Schema

The database consists of 16 tables organized into functional groups:

  • Pet Management: pet, breed, pettype, color - storing detailed information about boarded animals
  • Client Management: client, clientpet, citystatezip - managing client information and their pets
  • Employee Management: employee, position, employeeposition - tracking staff and their roles
  • Scheduling: workschedule, workscheduleview - managing employee work hours and shifts
  • Boarding Operations: board - tracking pet boarding reservations and stays
  • Financial: employeedeposit, ratetype, timecard - managing payroll and billing

Technical Implementation

Business Logic Automation

Payroll Deposit Calculation Function:

Developed a stored function that automatically calculates employee payroll deposits based on their work schedule and position rate type. The function aggregates hours worked, applies the appropriate rate, and computes the deposit amount, eliminating manual calculation errors and ensuring consistent payroll processing.

Data Validation Triggers:

Implemented triggers that enforce business rules such as preventing negative values for pet weights, validating age ranges, ensuring appointment dates are in the future, and maintaining referential integrity when updating or deleting records across related tables.

Technical Challenges & Solutions

  • Challenge: Managing complex many-to-many relationships between clients and pets
    Solution: Implemented junction table (clientpet) with proper foreign key constraints
  • Challenge: Calculating payroll across multiple work schedule entries
    Solution: Created stored function with aggregation logic and rate type joins
  • Challenge: Maintaining data consistency across 16 interconnected tables
    Solution: Utilized comprehensive constraint system and validation triggers
  • Challenge: Optimizing query performance for reports spanning multiple tables
    Solution: Designed database views and implemented strategic indexing
