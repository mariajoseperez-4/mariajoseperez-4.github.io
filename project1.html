Relational Database System

Project Description

This project involved designing and implementing a comprehensive relational database system using MySQL for managing a pet boarding business. The database consists of 16 interconnected tables that handle all aspects of pet boarding operations including pet information, client management, employee tracking, work schedules, and boarding reservations.

The system manages diverse entities such as pets (with breeds, types, and colors), clients and their relationships with pets, employees and their positions, work schedules, and boarding records. The database design follows normalization principles to ensure data integrity and eliminate redundancy.

Key features include stored functions for automated payroll deposit calculations based on employee work hours and position rates, triggers to enforce business rules and maintain data integrity, and complex SQL queries involving multiple table joins for reporting and data analysis.

The project required creating Entity-Relationship (ER) diagrams to visualize the database structure, implementing comprehensive constraints (primary keys, foreign keys, check constraints), and developing structured test cases to validate data accuracy and query correctness throughout the development process.
