Project Overview

Designed and implemented a three-tier enterprise web application using Java Servlets, JSP, Apache Tomcat, and a MySQL backend. The application supports multiple user levels with role-based authentication and authorization and enforces distinct database privileges by user type.

What I Built

  • Role-based authentication and authorization for multiple user levels.
