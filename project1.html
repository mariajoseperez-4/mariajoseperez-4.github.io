Three-Tier Distributed Enterprise Web Application

Project Overview

Institution: University of Central Florida

Location: Orlando, FL

Duration: August 2025 – December 2025

Project Image

Project Description

This project involved developing a comprehensive three-tier distributed enterprise web application using modern Java web technologies. The application follows enterprise architecture patterns with a clear separation between presentation, business logic, and data access layers.

The system was built using Java Servlets and JSP for the presentation and control layers, deployed on Apache Tomcat server, and connected to a MySQL database backend. The application implements sophisticated role-based authentication and authorization mechanisms that support multiple user levels, each with distinct database privileges and access rights.

The project demonstrates enterprise-level security practices, robust server-side business logic implementation, and efficient database operations using JDBC. The system handles various database operations including data retrieval, insertion, updates, and deletions through prepared statements and callable statements, ensuring both security and performance.

The application manages a supply chain system with multiple interconnected entities including jobs, parts, shipments, and suppliers, requiring complex relational database operations and transaction management to maintain data integrity across the system.

Technical Implementation

  • Frontend Layer: JavaServer Pages (JSP) for dynamic web page generation with embedded Java code
  • Application Layer: Java Servlets handling HTTP requests, session management, and business logic
  • Data Layer: MySQL relational database with normalized schema design
  • Server: Apache Tomcat container for servlet deployment and execution
  • Database Connectivity: JDBC for database operations using prepared and callable statements
  • Security: Role-based access control (RBAC) with user authentication and authorization
  • Architecture: Three-tier distributed system with clear separation of concerns

Key Features

  • Multi-level user authentication system with secure login mechanisms
  • Role-based authorization controlling access to different application features
  • Database privilege management at the user level for enhanced security
  • Server-side validation and business rule enforcement
  • CRUD operations across multiple database tables
  • Transaction management ensuring data consistency
  • Session management for maintaining user state
  • SQL injection prevention through prepared statements

Technical Challenges & Solutions

  • Challenge: Managing database connections efficiently across multiple concurrent users
    Solution: Implemented connection pooling and proper resource management with try-with-resources blocks
  • Challenge: Ensuring data security across different user privilege levels
    Solution: Designed role-based access control system with database-level privilege enforcement
  • Challenge: Maintaining session state across multiple requests
    Solution: Utilized HTTP sessions with proper session timeout and invalidation mechanisms
